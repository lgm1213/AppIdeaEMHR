# Design Standards: NextGenApp
- **CSS:** Use Tailwind CSS exclusively. No inline styles.
- **Responsiveness:** Mobile-first design. Use `sm:`, `md:`, and `lg:` prefixes.
- **Accessibility:** All icons must have hidden text or ARIA labels. Minimum contrast ratio of 4.5:1 for text.
- **Consistency:** Use the project-defined color palette and spacing scale (4px grid).
